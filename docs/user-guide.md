# RPG Maker Agent 用户指南

安装、更新和卸载请看 [Windows 安装与维护指南](windows-release.md)。本指南说明安装
完成后怎样使用唯一的默认助手：`🐒 制作猿`。

## 开始使用

从开始菜单启动 **RPG Maker Agent**，在 DSH Web 中选择你的 RPG Maker MV 项目
文件夹后直接描述目标。制作猿在同一会话中维护设计资料并修改项目；不需要先选择
策划或程序员。

每次具体变更前，它会读取项目、做一次定向修改、回读并验证。RPG Maker 编辑器若正
打开项目，只作为只读参考；在查看变更前请重新打开项目。

## 新会话快速开始

选定项目后，空白会话的输入框上方会显示四个常用入口：推敲游戏设计、修改当前项目、
制作图片素材和诊断 Playtest。每个按钮都会把标明对应 Skill 的可编辑起始提示填入输入
框，但不会自动发送；你可以继续补充目标、参考资料和约束。开始输入或会话进入工作状态
后，这一行会自动隐藏。你也可以跳过按钮直接描述自己的请求，Skills 仍会自动路由。

## 内置 Skills

| Skill | 何时使用 | 你可以怎样说 |
| --- | --- | --- |
| `game-design` | 机制、叙事、节奏、数值、玩家目标或持续维护的设计文档 | “把战斗循环和数值假设整理成设计文档，先问我真正会影响体验的问题。” |
| `game-design-bootstrap` | 项目还没有可维护的设计索引或主设计文档 | “先了解这个现有游戏，再建立最小的设计文档基础。” |
| `rpgmaker-mv` | 数据库、事件、对话、地图、插件、备份恢复或项目验证 | “给第一个地图加一个 NPC 对话，修改后验证项目。” |
| `playtest-debug` | Playtest 启动、日志和可复现的运行问题 | “启动一次有界 Playtest，检查这个报错并确认已停止。” |
| `image-assets` | 新图、图片编辑、像素缩放、透明清理、裁剪和精灵表准备 | “把这张角色图做成 4×2 的行走图；保持像素风格。” |

Skills 会按任务自动加载；你也可以直接说出目标和约束。设计文档与项目实现可以在同
一会话连续进行，制作猿会在真正影响玩家体验或不可逆的选择尚不明确时提问。

## 图片素材

需要生成新视觉候选或模型编辑时，制作猿使用 Kepos；裁剪、缩放、绿幕清理和精灵表
等确定性处理使用 Windows 全局 `magick` 命令。请说明素材用途、目标尺寸/网格、风
格或参考图；它只会追问会显著改变成品的未知项。

## 工具与 Skill 的区别

Skills 是制作猿选择工作方式的说明；它还可使用项目内的 RPG Maker MCP 工具来读取、
修改、备份和验证当前工作空间，并可使用 Forgejo MCP 处理仓库事项。它们不是额外的
角色，也不需要单独切换。
